# /public/images

Drop your team photo here. The About page is already configured to load it.

## Your profile photo
File name expected: image1.jpg  (or image1.png / image1.webp)

Just drop your photo here and rename it to:
  image1.jpg

It will appear automatically on the About page.
No code changes needed.

## Supported formats
  image1.jpg   ← recommended
  image1.png
  image1.webp

## Recommended specs
  Size:    800×800px (square crop)
  Format:  JPG for smallest file size
  Style:   Face centred, neutral background
